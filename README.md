# Hypelink — Hypelink Digital Website

Repository owner: tiffanyn
Repository name: Hypelink

This directory contains the website skeleton for Hypelink Digital — a digital, marketing, and recruiting company focused on insurance recruiting for district managers.

Local workflow:
- Add brand assets to `assets/`
- Edit copy in `index.html` and add pages in `pages/`
- Test locally by running the included `serve.ps1` (serves on http://localhost:3000)
- Initialize git, push to `github.com/tiffanyn/Hypelink`, then connect to Vercel

Local testing
------------
Windows PowerShell: run `.
serve.ps1` from the project root to serve the site on port 3000 using Python if available.
